Cara Overclock GPU Unisoc GUIDE by @KurumiDev2

Alat:
Laptop/Pc yang sudah di pasang operating system ubuntu atau distro linux lainnya

Bahan:
Vendor_boot.img bisa ambil dari firmware
Tools Unpac Repac .img: https://drive.google.com/file/d/1Ia4Y8OcGSeCc0nrrnZ_rihtaXzxoPekE/view?usp=drivesdk

Proses Overclock:
1. Buat folder baru
2. Extrak tools unpac repac yang udah di download
3. Pindahkan semua bahan ke folder yg sudah di buat
4. Jalankan perintah ini
   1. ./magiskboot unpack vendor_boot.img
   2. hexdump -v -e '/1 "%02x "' dtb | grep -b -o "d0 0d fe ed"
      kalau keluar angka ini 192:d0 0d fe ed lanjutkan saja jika tidak ada atau angka nya beda silahkan tanya AI ini script saya dapat dari AI Gemini
   3. dd if=dtb of=clean.dtb bs=1 skip=64
   4. ./dtc -I dtb -O dts -o modified_dt.dts clean.dtb
      disini kalian buka file modified_dt.dts nya dan cari teks ini:

  5. ./dtc -I dts -O dtb -o dtb_mod modified_dt.dts
  6. dd if=dtb count=64 bs=1 > header.bin
  7. cat header.bin dtb_mod > dtb_final
  8. ./magiskboot repack vendor_boot.img
  9. Jika udah maka akan muncul file baru namanya new-boot.img tinggal flash aja new-boot.img di fastboot


Cara Flash Hasil Overclock GPU Unisoc:
1. Masuk fastboot pakai adb reboot fastboot
2. Flash new-boot.img pakai command ini fastboot flash vendor_boot [ tarik file new-boot.img ke cmd ubuntu/distro linux kalian ]
3. Tinggal kalian reboot system jika sudah di flash cara nya ketik fastboot reboot
4. Udah gitu doang kalau boot tinggal check frekuensi gpu kalian udah ke ubah/belum jika bootloop/stuck/hitam doang tinggal flash vendor_boot sebelum di unpac alias vendor_boot firmware
5. Sekian terima kasih :)
